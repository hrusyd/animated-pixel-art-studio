# Contributing

Open an issue with the expected behavior, minimal scene JSON, command, OS/Python/Pillow versions, and actual error. Remove private paths or assets before posting. Do not upload credentials or unlicensed artwork.

Keep the skill folder portable and the renderer deterministic. Add focused tests for behavior changes, run the suite, render an example, and inspect the contact sheet. Video changes should also be tested with FFmpeg/ffprobe. Include actual validation in the pull request, distinguishing local checks from CI.

Keep English and Indonesian quick starts aligned. New examples should be original, have explicit licensing, and demonstrate a different animation technique rather than recoloring an existing scene. Avoid heavy dependencies for features that can remain optional.
